# 考务导入（从头到尾）

模拟一条真实业务：教务处发模板，班主任交表，系统校验入库，填错的退回改完再导，最后导出已录取名单。

```bash
go run ./examples/enrollment
```

过程文件默认写到 `examples/enrollment/out/`（可用 `-dir` 改）：

| 文件 | 谁产生 |
|------|--------|
| `1-考生模板.xlsx` | 教务处 `Write` + `Template` + 年级下拉 |
| `2-班主任交回.xlsx` | 按模板填写；含缺姓名、短身份证、年级填成 C |
| `3-退回-带错误列.xlsx` | `WriteErrors`：只保留失败行，并加上错误原因 |
| `4-班主任改完.xlsx` | 在退回表上改完的 3 行 |
| `5-已录取名单.xlsx` | 从报名库 `Write` 导出 |

第一次入库 3 人；退回改完再导，又录取 3 人，名单共 6 人。
